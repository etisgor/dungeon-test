# Dungeon

[Play Dungeon](https://etisgor.github.io/dungeon-test/)

This repository publishes the compiled Dungeon browser client. GitHub Pages deploys the contents of `site/` after checking the offline release hashes.

Open the game online until it shows **Ready to play offline**. Find the build version next to the Dungeon title and open **Controls** for movement and combat help.

To report a playtest issue, include the build version, browser and device, steps to reproduce, what you expected, and what happened. If the issue involves an update or offline play, include whether the game showed offline readiness first. [Report a playtest issue](https://github.com/etisgor/dungeon-test/issues/new)

See the [contributor instructions](AGENTS.md) for the release and Pages checks.
