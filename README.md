# Dungeon

[Play Dungeon](https://etisgor.github.io/dungeon-test/)

This repository publishes the compiled Dungeon browser client. GitHub Pages deploys the contents of `site/` after checking the offline release hashes.

Open the game online until it shows **Ready to play offline**. Build version is shown under the Dungeon title. This playtest is designed for touch: tap the world to travel or interact with a site; turn off the camera icon to swipe-pan; use the bottom icons for Character, Journal, Cargo, and Settings. In Character, drag items between equipment, backpack, and loot, or tap an item and then a target slot.

To report a playtest issue, include the build version, browser and device, steps to reproduce, what you expected, and what happened. If an issue involves an update or offline play, include whether the game showed offline readiness first. [Report a playtest issue](https://github.com/etisgor/dungeon-test/issues/new)

See the [contributor instructions](AGENTS.md) for the release and Pages checks.
